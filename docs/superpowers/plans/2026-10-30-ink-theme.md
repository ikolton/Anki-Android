# AnkiDroid Ink Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A personal AnkiDroid fork that looks like the owner's desktop "ink & saffron" Anki, installs next to official AnkiDroid, and ships signed APKs from GitHub that keep up with upstream releases.

**Architecture:** One branch `ink` on top of the upstream stable tag `v2.25.3`. The palette is a theme overlay applied in one place (`Themes.setTheme`), so upstream theme files stay untouched. Study-screen changes are confined to the new study screen's own layouts and two small views. A GitHub Actions workflow rebases `ink` onto new stable tags and publishes signed release APKs.

**Tech Stack:** Kotlin, Android XML resources (Material 3), Gradle (Groovy `AnkiDroid/build.gradle`), Robolectric unit tests, GitHub Actions, `gh`.

**Spec:** `docs/superpowers/specs/2026-10-30-ink-theme-design.md`

## Global Constraints

- Work in the worktree `~/Documents/MyProjects/Anki-Android-ink`, branch `ink`, based on tag `v2.25.3`. Never commit to `main`.
- No functional changes; no upstream PRs (AnkiDroid `AI_POLICY.md`).
- Keep the diff small: do not edit upstream theme files (`theme_dark.xml`, `theme_light.xml`, `values-v29/*`) or translation files (`values-*/0*-*.xml`); add new `ink_*` resource files instead.
- Release package id `com.ichi2.anki.ink`, app name `AnkiDroid Ink` (via existing `-PcustomSuffix=ink -PcustomName="AnkiDroid Ink"`).
- Dark tokens: canvas `#12161f`, surface `#1c2230`, line `#262d3d`, fg `#e9ebf1`, muted `#8a93a7`, accent `#e9b35f`, accent soft `#1FE9B35F`, on-accent `#1a1406`, new/learn/review `#8fb0f2` / `#ee9a8b` / `#93cfa5`.

- Polish answer labels: `Jeszcze raz` / `Trudne` / `Dobrze` / `Łatwe`. English fallback: upstream `Again` / `Hard` / `Good` / `Easy`.
- Never grade cards in the owner's real collection. Emulator only, with `tools/test-decks/*.apkg` or a generated test deck.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Light theme / system day mode:** every changed screen must be legible in light mode, not only dark. Task 2 tests both overlays; Task 7 screenshots both.
2. **"Hide hard and easy buttons" preference on:** the 2×2 grid must collapse to one row of Again + Good, not leave holes. Task 6 test.
3. **Show remaining counts off** (`CollectionPreferences.getShowRemainingDueCounts() == false`): the progress row must hide like the counts did. Task 5 keeps the existing `isVisible = false` branch on the same view.
4. **Undo after answering:** the progress must not run past 100% or below 0. Task 5 test clamps.
5. **Upgrade path:** a rebuilt `ink.N+1` on the same upstream version must install over `ink.N`, and the next upstream release must install over both. Task 1 test (versionCode) and Task 8 verification.

Never print the password in chat.
- [ ] **Step 2: Workflow** `ink-release.yml`, triggers `schedule: cron "0 6 * * 1"` and `workflow_dispatch` (input `force`, boolean). Job steps:
  1. checkout `ink` with full history; `git fetch https://github.com/ankidroid/Anki-Android.git --tags`.
  2. `latest` = highest tag matching `^v[0-9]+\.[0-9]+\.[0-9]+$` (sort -V); `base` = `cat ink/BASE`.
  3. If `latest != base`: `git rebase --onto "$latest" "$base" ink`; on failure `git rebase --abort`, `gh issue create --title "Ink: konflikt przy przejściu na $latest"` with the conflicting files, and fail. On success write `latest` to `ink/BASE`, commit, `git push --force-with-lease origin ink`.
  4. Skip the build unless the base changed, `ink` has commits since the last `*-ink.*` release, or `force`.
  5. `N` = 1 + count of existing releases `v$latest-ink.*`; set up JDK 17; decode keystore; `./gradlew :AnkiDroid:assembleFullRelease -PcustomSuffix=ink -PcustomName="AnkiDroid Ink" -PinkBuild=$N -Duniversal-apk=true`.
  6. `gh release create "v${latest#v}-ink.$N"` (keep the leading `v`) with the arm64 and universal APKs, notes = `git log --oneline $latest..ink`.
  Permissions: `contents: write`, `issues: write`.
